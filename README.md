# Voice Benchmark

This project evaluates multilingual AI performance in speech recognition, with a focus on differences across languages and their potential impact on accuracy and cost.

## Current Work

This repository includes experiments using the **FLEURS** dataset to evaluate Automatic Speech Recognition (ASR) models across multiple languages.

The current benchmark includes:

* 10 languages
* 50 audio samples per language
* Multiple ASR models
* Word Error Rate (WER) for performance comparison

More documentation, experiments, and results will be added as the project progresses.
